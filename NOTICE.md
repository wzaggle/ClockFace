# Artwork and distribution notes

The original Lua script and eighteen PNG assets were supplied by the user. Their
original redistribution terms have not been established in this project. The
original PNG names are dial.png through dial5.png and hour/minute/second PNGs
with unnumbered, 1, 2, and 3 suffixes.

The new plugin code and generated clock artwork are provided under
GPL-2.0-or-later; the license text is in LICENSE. Do not infer that this statement
establishes redistribution rights for the original user-supplied artwork.
Review those terms or replace the affected originals before public distribution.

The ClockFace icon and ten-concept illustration were generated for this project.
The illustration is a design reference, not a screenshot or a set of bundled
backgrounds. Coastal and Copper illustrate custom-image configurations.
