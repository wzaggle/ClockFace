# OBS Clock

OBS Clock is a native analog-clock source for OBS Studio 33, with selectable faces
and hands, custom backgrounds, independent markings/colors, time zones, and a
scheduled daily message displayed on the clock or in a dedicated OBS text source.

## 1.1.0 development candidate

This revision adds a macOS/Linux text and time-zone backend while preserving the
Windows GDI backend and the `simpleclock_source` compatibility ID. The accepted
Windows 1.0.4 release remains the baseline. Native cloud builds produce Windows, Mac Intel, Mac Apple silicon, and Ubuntu
installers from the same source revision. Live OBS acceptance testing remains
the next step. Download packages through the build run linked below.

## GitHub builds

[Build All Platforms](.github/workflows/build-all.yml) compiles the same commit on:

- Windows x64, producing an Inno Setup EXE and manual ZIP.
- Apple silicon macOS arm64, producing a per-user PKG and manual bundle archive.
- Intel macOS x86_64, producing a per-user PKG and manual bundle archive.
- Ubuntu 26.04 x64, producing a native DEB.

All four jobs run automated tests. The combined artifact is produced only after
all four jobs pass and their source revisions match. Workflows do not publish a
GitHub release or install anything on the user's computer. Flatpak is a separate
Linux packaging target and is not yet generated by this workflow.

See [cloud builds](docs/CLOUD_BUILDS.md), [build notes](docs/BUILDING.md),
[testing](docs/TESTING.md), [user instructions](USER.md), and [agent rules](AGENTS.md).

## Build and download

Open [the matching installer build](https://github.com/wzaggle/OBS-Clock/actions/runs/41390335998).
Download the combined **OBS-Clock-AllPlatforms** artifact, or an individual
**packages-windows**, **packages-macos-arm64**, **packages-macos-x86_64**, or
**packages-linux** artifact. GitHub sign-in is required for this private project.
Actions artifacts expire after seven days; retain downloaded test packages locally.
Each contains the Word guide, Markdown instructions, license, build metadata and
checksums. The repository keeps the full source, artwork, AGENTS.md and build scripts.

## Validation and testing scope

Windows native compilation and portable tests; both Mac architectures' compilation,
time/text tests, signatures and per-user PKG installation; and Ubuntu compilation,
time/text tests and DEB packaging are checked by GitHub Actions. The collector
requires passing tests and identical source revisions across the four packages.
See the linked run for the recorded result. These checks do not establish live
OBS rendering, source migration, or production acceptance on each platform.

The Linux DEB targets native Ubuntu 26.04 OBS 33.0.1+, using the OBS 33 module
layout. Flatpak needs its own extension package and is not included in this set.
Mac test packages are ad-hoc signed, not Developer ID signed or notarized.
